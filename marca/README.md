# Icono de Cuentacasa

Una casita cuyo tejado es un libro abierto boca abajo, sobre terracota (#A9532E).

| Archivo | Para qué |
|---|---|
| `icon.svg` | Original vectorial. Edita este y vuelve a exportar. |
| `icon-maskable.svg` | Igual, con margen para recortes en círculo (Android, redes). |
| `app-store-1024.png` | App Store (iOS lo redondea solo). |
| `google-play-512.png` | Google Play. |
| `redes-perfil-1080.png` | Foto de perfil en Instagram, TikTok, Facebook, etc. |
| `redes-compartir-1200x630.png` | Imagen al compartir el enlace (también en `public/og-image.png`). |

En `public/` están los de la web: `favicon.ico` (16, 32 y 48 px), `favicon-32.png`, `apple-touch-icon.png` (180 px), `icon-192.png`, `icon-512.png` e `icon-maskable-512.png`.

Colores: terracota #A9532E, crema #FBF5E8 y #EADFC8, dorado #F2C76B y #E2A93B, lomo #7A3A1E.
